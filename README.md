## 1. Теоретическая база

Сверточные нейронные сети (Convolutional Neural Networks, CNN) — это класс глубоких нейронных сетей, широко применяемых для анализа изображений. Основные особенности CNN:

- использование сверточных слоев для автоматического выделения признаков;
- уменьшение размерности с помощью pooling-слоев;
- устойчивость к сдвигам и локальным искажениям изображения.

Типовая архитектура CNN включает:
- сверточные слои (Conv2D);
- функции активации (ReLU);
- слои подвыборки (MaxPooling);
- полносвязные слои (Fully Connected);
- выходной слой с Softmax (для многоклассовой классификации).

## 2. Описание разработанной системы

### Назначение системы
Разработанная система предназначена для классификации изображений по заранее заданным классам на основе сверточной нейронной сети.

### Архитектура модели
В работе используется модель CNN, реализованная с помощью **PyTorch**, включающая:
- несколько сверточных слоев;
- слои подвыборки (MaxPooling);
